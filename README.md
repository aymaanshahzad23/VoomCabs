# VOOM Cabs Waitlist

Single-page waitlist landing for VOOM Cabs, built with Next.js and Tailwind.

## Quick start

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Environment variables

Create `.env.local`:

```bash
NEXT_PUBLIC_SUPABASE_URL=your_supabase_project_url
SUPABASE_SERVICE_ROLE_KEY=your_supabase_service_role_key
ADMIN_USERNAME=your_admin_username
ADMIN_PASSWORD=your_admin_password
```

## Admin dashboard

- URL: `http://localhost:3000/admin`
- Access is protected by HTTP Basic Auth via `ADMIN_USERNAME` and `ADMIN_PASSWORD`.
- Dashboard shows:
  - Total waitlist signups
  - Today's signups
  - Latest 500 signup rows

## Supabase table setup

Create the waitlist table:

```sql
create table if not exists public.waitlist_signups (
  id bigint generated by default as identity primary key,
  email text not null unique,
  full_name text,
  city text,
  source text,
  created_at timestamp with time zone default now()
);
```

Enable insert access using the service role key on server routes only.
